MY LITTLE MONEY HOME — LOCAL Y2K SAVING APP
============================================

WINDOWS
1. Unzip the app somewhere you want to keep it.
2. Double-click START_MONEY_HOME.bat.
3. The app opens at http://localhost:8000.
4. Leave the little server window open while you use the app.

YOUR DATA
- No bank connection.
- No account.
- No cloud database.
- Data and item photos stay in browser storage for http://localhost:8000.
- Photos are resized before they are stored.
- Use the Backup button sometimes. Clearing browser data can erase local data.

THE FLOW
Wishboard -> Waiting Room -> you choose -> Envelope -> Fun Money Game -> Ready -> Buy / Keep / Better / Let Go

WHAT CHANGED IN THIS VERSION
- Clean-slate default: $0 saved, no fake paycheck, no fake rent, no sample wishlist.
- Old built-in sample items are stripped during migration from the earlier version.
- Photo-first Pinterest-style Wishboard.
- Upload a photo for a wanted item or an impulse buy.
- Visible Delete controls for paychecks, bills, savings goals, sinking funds,
  wishes, envelopes, roll deposits, impulse buys, notes, and Memory Box entries.
- Oops! area for accidental/impulse purchases.
- Oops purchases can honestly deduct from the Fun Money Jar, even making it
  negative if you overspent your current fun-money allocation.
- Returned impulse buys stop deducting from Fun Money.
- My Rules sticky-note board for no-spend goals, shopping rules, and reminders.
- Simpler visual home screen with fewer explanations and more icons/pictures.
- Category folders stay inside the Wishboard instead of creating a maze of tabs.
- Waiting Room still does not auto-promote after 30 days. You choose.
- Active envelopes automatically enter the dice game.
- Fully funded envelopes automatically leave the dice pool and cool off before
  a final decision.
- Letting go of a funded wish returns its envelope deposits to the Fun Money Jar.
- Paycheck history, recurring bills, sinking funds, savings goals, windfalls,
  paycheck allocation snapshots, game modes, better-version tracking, backups,
  and post-purchase joy ratings are still included.

LOCAL STORAGE NOTE
Browser local storage is convenient and private for a personal prototype, but it
is not the same thing as a durable encrypted database. Export backups regularly.
For a future iPhone build, the same interface can be moved to proper on-device
app storage without putting your financial data on a cloud server.
