MY LITTLE MONEY HOME — iPHONE / PWA BUILD

THIS IS A STATIC, LOCAL-FIRST WEB APP.
The web host serves only the app files. Your money records, photos, GIFs, closet, notebooks, wishes, rolls and impulse-buy history stay in Safari/iOS storage on that device unless you explicitly export a backup.

TO PUT IT ON AN iPHONE
1. Upload this folder to any static HTTPS host (GitHub Pages, Netlify, Cloudflare Pages, etc.). No database or server code is needed.
2. Open the HTTPS URL in Safari on your iPhone.
3. Tap Share > Add to Home Screen.
4. Turn on “Open as Web App” if iOS offers it, then Add.
5. Open Money Home from its icon.

IMPORTANT
- Do not use Private Browsing for your real data.
- Use the app's Export Backup regularly. The backup includes your locally stored photos/GIFs.
- Deleting the web app/site data can delete its local data if you have no backup.
- Custom wallpapers, uploaded photos and GIFs are stored in IndexedDB on-device.
- Transparent PNG/iPhone cutout stickers are supported; non-GIF images are resized to save space.
